# Site デザイン規則

[English](DESIGN.md)

Tokfuel の静的サイト（Ignite）向けの見た目の約束。Apple の製品ページと
ドキュメントの空気（余白、左寄せ、システム書体、ブルーの CTA）を参考にする。
実装の正本は `Sources/Site/Theme.swift` と `Assets/css/tokfuel.css`。

## 原則

1. **左寄せ**：本文・見出し・CTA・リストは左揃え。中央寄せのヒーローは使わない。
2. **余白を先に取る**：セクション間は広く、要素間は一定。詰め込まない。
3. **情報の階層は文字サイズとウェイトで**：枠線カードや影で階層を作らない。
4. **ブランドはヒーローで一目**：最初のビューポートで Tokfuel が主語になる。
5. **装飾より可読性**：グラデーションの多用、グロー、絵文字装飾は避ける。

## カラー

| 役割 | Light | Dark | 備考 |
|------|-------|------|------|
| 背景 | `#ffffff` | `#000000` | ページ地 |
| セクション地 | `#f5f5f7` | `#1d1d1f` | Apple のグレー帯 |
| 本文 | `#1d1d1f` | `#f5f5f7` | |
| 副文 | `#86868b` | `#a1a1a6` | |
| アクセント / リンク / CTA | `#0071e3` | `#2997ff` | Apple ブルー系 |
| ナビ | `#000000` | `#000000` | 文字は白。端から端まで（`Body.ignorePageGutters` + `NavigationBar.width(.viewport)`） |
| ページ地（Dark） | — | `#010101` | 純黒 `#000` は Ignite の `Color.default` と同一扱いで `--bs-body-bg` が落ちるため近黒を使う |
| 罫線 | `#d2d2d7` | `#424245` | 必要なときだけ |

紫系グラデーションや暖色クリーム地は使わない。

## タイポグラフィ

- 本文・見出しとも **システム UI 書体**（`-apple-system`, `BlinkMacSystemFont`,
  `"Helvetica Neue"`, sans-serif）。Web 専用の Inter / Roboto は入れない。
- コードは SF Mono / Menlo 系。
- 見出しは太め・字間をやや詰める。本文の行間は約 1.47。
- ドキュメント本文の最大幅はおおよそ **720px**。マーケティング帯は最大 **980px**。

## レイアウト

- Ignite の `VStack` は **`alignment: .leading`** を明示する（省略時は中央寄せになる）。
- ページ左右のパディングはおおよそ 32px（狭い画面では CSS で縮める）。
- Docs は左サイドバー + 本文。現在ページもリンクのまま（`is-current`）にし、タップで目次の箱がずれないようにする。
- 日本語 Docs は BudouX（`budoux-ja`）で折り返し位置を整える。
- 上部ナビは Ignite の `NavigationBar`（Bootstrap sticky navbar）。スクロール中も常時表示する。

## 上部ナビの約束（疑って決めた結果）

並びに意味を持たせる: **Tokfuel · 検索ボックス · 言語アイコン · テーマアイコン · GitHub ★**。

| 項目 | 入れる理由 | やらなかったこと |
|------|------------|------------------|
| Docs リンク | — | ブランド自体がホーム／Docs への入口。ナビに Docs を重ねない |
| 検索ボックス | ナビ内でそのまま探せる。結果はドロップダウン。`/` でフォーカス | モーダル起動の Search リンク |
| 言語アイコン | 対訳ページへ1クリック（翻訳アイコン）。ツールチップで English / 日本語 | 文言の English / 日本語をナビに並べない |
| テーマアイコン | 明暗トグル。月＝ダークへ、太陽＝ライトへ | Light / Dark の文言リンク |
| GitHub ★ | OSS ドキュメントの定番。スターはライブ取得 | スター数が少なくてもリンク自体は残す |

言語アイコンは対訳ページへ（ホームは `/` ↔ `/ja`、Docs は同トピック同士）。ブランドロゴも言語に合わせてホームへ戻る。

## コンポーネント

- **上部ナビ**：上表のとおり。
- **Search**：ナビ内ボックス + `Assets/js/search-index.json`。`/` キーでフォーカス。
- **CTA ボタン**：塗りはアクセントブルー、角丸は中程度（極端な pill や多層影は避ける）。
- **リンク**：下線またはブルー。ホバーで少し明るく／濃く。
- **カード**：既定では使わない。操作のまとまりが必要なときだけ薄い背景または罫線。
- **ヒーロー画像**：製品スクリーンショットを実寸に近い形で。コラージュや浮遊カードにしない。

## モーション

- テーマ切替以外の派手なアニメは入れない。必要ならフェードや短いホバー程度。
