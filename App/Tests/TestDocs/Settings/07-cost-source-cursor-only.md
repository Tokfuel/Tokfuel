## シナリオ

コストのソースを Cursor のみにすると、ホームは Cursor のコストだけを表示します。

## 完了条件

- **E2E**
  - Cursor のみのとき、ホームが Cursor の表示になる

## 経路

### Cursor のみになる

- **Given**：Cursor のフィクスチャがある
- **When**：コストのソースを Cursor のみにした時
- **Then**：ホームが Cursor のみの表示になる
