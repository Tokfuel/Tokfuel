## シナリオ

Codex CLI がインストールされている Mac では、コストのソースに Codex のみを選べます。

## 完了条件

- **E2E**
  - Codex があるとき、コストのソースに Codex のみが見える
  - 選ぶとホームが Codex のみの表示になる

## 経路

### Codex のみを選べる

- **Given**：Codex が検出される環境である
- **When**：コストのソースを Codex のみにした時
- **Then**：ホームが Codex のみの表示になる
