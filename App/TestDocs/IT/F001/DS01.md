## シナリオ

ユーザーがポップオーバーの「モデル別」を見ると、Cursor の長いモデル ID も省略されず全文で読めます。

観測するのはモデル別の各行のモデル名までです。高コストセッションなど他セクションは対象外です。

## 完了条件

- **UT&IT**
  - モデル別行に渡す表示文字列が、モデル ID を省略しない
  - 名前列の最小幅が、短い固定幅より広い
- **VRT**
  - 長い Cursor モデル ID を含むモデル別の見え方が、プレビュー用フィクスチャとして固定されている

## 経路

### 表示文字列がモデル ID 全文になる

- **Given**：モデル ID が `cursor-grok-4.5-high-fast` である
- **When**：モデル別行の表示文字列を組み立てた時
- **Then**：表示文字列が `cursor-grok-4.5-high-fast` と一致する

### 名前列が短い固定幅より広い

- **Given**：モデル別行のレイアウト定数がある
- **When**：名前列の最小幅を参照した時
- **Then**：最小幅が 100pt より大きい
