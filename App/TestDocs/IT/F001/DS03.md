## シナリオ

ui-preview とスクリーンショット用のフィクスチャに、長い Cursor モデル ID が含まれます。レビュアーがモデル別の全文表示を絵で確認できます。

観測するのはフィクスチャのモデル別内訳までです。ライブな Cursor API 応答は対象外です。

## 完了条件

- **UT&IT**
  - Cursor のモデル別フィクスチャに、`cursor-grok-4.5-high-fast` が含まれる
  - Cursor のモデル別フィクスチャ合計が、今日の Cursor コストと一致する
- **VRT**
  - 既定のポップオーバープレビューに、長い Cursor モデル ID が写る状態が固定されている

## 経路

### フィクスチャに長いモデル ID を入れる

- **Given**：スクリーンショット用の Cursor モデル別内訳がある
- **When**：そのキー一覧を見た時
- **Then**：`cursor-grok-4.5-high-fast` が含まれ、合計は今日の Cursor コストと一致する
