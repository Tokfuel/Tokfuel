## 完了条件

完了条件は手段ごとのステップ箇条書きです。進捗や実装手段の詳細は書かない（`status` / `## 対応済みPR` へ）。

- **UT&IT**
  - （例: モデル別の行に、長いモデル ID が省略されず入る）
  - （例: 金額列は右寄せのまま残る）
- **VRT**
  - （例: 長い Cursor モデル ID を含むモデル別画面が、視覚的に固定されている）

原則は **UT&IT** と **VRT** の 2 手段です。UT&IT は振る舞いを UT と／または IT で担保するまとまりです。当面はフィクスチャと部分モックで足り、メニューバー操作の画面貫通 E2E は必須ではありません。  
備考は真の制約（例: 異常系は別観点）があるときだけ書き、進捗・未着手・実装手段は書かない。

経路ごとの再現手順は次の「## 経路」に書きます。完了条件を経路の下には置きません。

## 経路

**経路**は、実装するテスト（スイート）単位です。1 観点は複数経路（複数テスト）になり得ます。  
見出しは振る舞いのみにします（クラス名は書かない。Bad: `### PopoverViewTests` / Good: `### 長いモデル ID を全文表示する`）。その下に GWT を書きます。  
節名に「前提条件」は使いません（前提は Given に書きます）。

**Then** は Store / Settings / 表示用の状態を主に expect します。ネットワーク呼び出し回数などは補助観測とし、主検証にはしません。
